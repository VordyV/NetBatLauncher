## Introduction

**NBL2142** is a free game launcher for simple and enjoyable play in **Battlefield 2142**. The main goal of the project is to provide the user with a sufficiently convenient tool both for launching the game itself and for managing resources

## What can it do?

- Automatically update itself when a new version is released. The user will be prompted to perform an upgrade if their launcher version becomes outdated;
- Launch on different platforms, NovGames or Respy and others.
